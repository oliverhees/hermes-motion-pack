# Interview bank — question sets per video type

Use the set that matches the type. Each line is one tap-question with options.

## Product spot (30–60 s)
- What is the ONE feeling after watching? (relief · excitement · trust · curiosity · you decide)
- Problem → solution in a sentence? (ask, or propose 2)
- Which 3 features must be visible? (list from the website, let them tick)
- Real UI or stylised UI? (screenshots · captured from URL · abstract mock-up)
- End card: logo + URL · logo + CTA · QR code

## Social reel 9:16 (6–30 s)
- Hook style: bold claim · question · number · "stop doing X" · before/after
- Text density: 1 word per beat · short lines · full sentences
- Voice: none (on-screen text only) · voice-over · voice + captions
- Loop it? (yes · no)
- Platform safe zones: TikTok · Instagram Reels · YouTube Shorts (changes bottom margin)

## Launch teaser (6–15 s)
- Reveal what? (product name · date · feature · "something is coming")
- Mood: dark cinematic · bright playful · minimal typographic
- Date/wordmark as the only hard content? (yes · also 1 feature · also a tagline)

## Logo sting / loop (2–6 s)
- Source logo as SVG? (yes · PNG only · need to recreate — stop, ask for SVG)
- Behaviour: build-up from parts · reveal through mask · morph from shape · type-on
- Loop or one-shot? Sound: whoosh+hit · soft pad · silent

## Kinetic typography (10–30 s)
- Text source: given script · quote · lyrics · we write it
- Rhythm: words on beat · phrases · mixed
- One font family or two? (ask for the font or offer: Inter/Space Grotesk/Instrument Serif/IBM Plex)

## Data story (15–45 s)
- Numbers + source? (paste · URL · we research)
- Chart types allowed: bar · line · counter · comparison · map
- Takeaway sentence?

## UI showcase (15–45 s)
- Screens: screenshots · URL to capture · Figma export
- Narrative: task completed step by step · feature tour · before/after
- Cursor visible? (yes · no) Device frame? (none · phone · laptop)

## Highlight reel from footage (20–60 s)
- Where is the material? (folder path · drive · "I'll upload") How much? (minutes/hours)
- Intent: action/energy · emotion/story · recap/overview
- Music: file given · pick a mood (epic · hype · emotional · minimal) + bpm
- Delivery: 16:9 · 9:16 · both (needs reframing per shot)
- Must-include moments? (timestamps or descriptions) · People to avoid?

## Trailer / teaser (15–45 s)
- Basis: my footage · AI clips · code only · mix
- The reveal: name · date · tagline · "coming soon"
- Tone: dark epic · bright hype · mysterious · playful
- Title words you want on screen? (≤ 4 per card)

## Event recap / aftermovie (30–90 s)
- Footage folder + 3–5 numbers to show (attendees, talks, countries …) with source
- Highlights that must appear (keynote, party, sponsor wall)
- End card: thank-you · next date · CTA
